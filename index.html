Auto-detect reads the frame size from a _wt1024 suffix in the filename or from a Serum clm chunk, then falls back to 2048. A short file is treated as one cycle. Tables with more than 64 frames are thinned to 64 evenly spaced frames, the same as Tonverk does. Several WAVs at once (or a folder) become one table with one keyframe per file. Vital .vitaltable and .vital files load their wave keyframes; extra tables in a preset go to the bank. Serum wavetables are plain WAVs and load like any other.

Spectrum reads each frame's line of pixels as a harmonic spectrum: low harmonics on the left (or at the bottom when reading columns, like a spectrogram), and brighter pixels are louder. Waveform reads the line as the wave itself: black is −1, white is +1. Curve bends brightness before it's used (higher keeps only the bright parts). Roll-off tames the top end so a bright image doesn't buzz. The highlighted line on the image follows the scan position. Click the image to scan to that line. Changing a setting runs it again. Images aren't saved in the project.

Keyframes

The frames between keyframes are generated by the morph. Spectral blends harmonic levels, so it avoids the volume dip a plain crossfade has when waves are out of phase. The Table… menu works on every keyframe at once: Reverse frame order flips the table end to end, transform sweeps included; Remove DC centres every keyframe; Fade frame edges fades the first and last 1/64 of each cycle to zero, which removes clicks at the loop point.

Each transform sweeps from Start (frame 1) to End (last frame). Chain runs top to bottom.

Each transform runs on every frame after the morph and moves from its Start value at frame 1 to its End value at the last frame. The chain runs top to bottom; use ↑ ↓ to reorder it. Waveshaping transforms run at 4× resolution and are band-limited afterwards, so they don't alias. Frames that clip are pulled back to full scale. Even out loudness fixes the volume wobble resynth and fold tables get when you scan them. The table view, audition and export are wet; keyframe thumbnails stay dry.

Notes play a polyphonic wavetable voice, so you hear the table the way a scanning synth plays it: the position glides between frames instead of jumping. The Scan slider, Sweep and the MIDI scan CC set the base position; the mod envelope and LFO move it from there, and the envelope can open the filter too. Each octave uses a band-limited copy of the table, so high notes don't alias. Synth settings are saved with the project but don't affect the exported WAV.

Starter tables built from shapes, harmonic recipes, formulas, transform sweeps and fixed generator seeds, so they're the same every time. Hovering a card (or focusing it with Tab) shows it in the table view through the Snapshot slot, and can play a note at the current octave; moving away puts the slot back. Load (or double-click, or Enter) replaces the current table and can be undone. A/B keeps it in the Snapshot slot so you can compare while you edit.

Everything here is seeded: the same seed (and amount) always gives the same result, and the seed goes into the name so you can get back to it. Random table picks 2–5 keyframes from shapes, harmonic recipes and formulas, a morph mode and up to three transforms. Mutate reshapes each keyframe's harmonics with a random EQ curve, nudges the transform settings and sometimes adds one. Add to bank makes variations from seed, seed+1, seed+2…; the Bank then exports them as one ZIP.

Click a step to jump there; ⌘Z / ⌘⇧Z walk the highlighted line. Editing after a jump starts a new branch and the old one stays here, faded. ☆ pins a step as a named snapshot; Compare loads it into the A/B Snapshot slot. The last 80 steps are kept, and pinned snapshots survive even after their step is dropped.

edited

Template fills in the settings for an instrument and sets the README and report wording; change anything afterwards and it shows as edited. Safe file name keeps file names to letters, digits, _ and -, strips accents and cuts long names so they show up cleanly on hardware screens and copy to a FAT card without surprises. Tuned to sets the frame size to one cycle of a note at the chosen rate (C4 is middle C), for instruments that play frames at a fixed length instead of retuning them; the rate then matters too. Otherwise the sample rate is only written to the header and doesn't change the sound of a wavetable.

Each table in the bank is rendered with the template, frame size, format and options from Export, and named from its row. Load brings a table back into the editor (undoable); Overwrite replaces the row with what's in the editor now. The bank is saved with the project.

WAV folder + extras puts the WAVs alone in one folder named after the bank, ready to drag onto a card or into a synth's wavetable folder, and the project, report and a README in extras/ so they don't clutter the browser. Loudness evens out level across the bank by RMS, so switching tables doesn't jump in volume: match all tables brings every table to the level of the one with the least headroom, so nothing clips; match to the typical table uses the median level and lets tables that would clip stay at full scale (the report marks them). Either one replaces Normalize table for the ZIP.
